# Media placeholders

Drop your own licensed media here:

- `bg-video.mp4`  - looping gaming montage for the full-page background
                    (any clip you have rights to; H.264 MP4 works everywhere).
                    If missing, the site renders its built-in animated
                    gradient scene instead.
- `intro-voice.mp3` - the monstrous "El-Masry Store" voice that plays on
                    the intro splash (already generated and included).
- `ambient.mp3`   - optional: your own ambient loop. The built-in Web Audio
                    synth pad plays by default.

Game covers and wallpapers are generated in CSS from each game's gradient
pair (see `src/data/games.js`). Replace them with licensed key art when you
have it.
